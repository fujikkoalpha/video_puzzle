動画で15パズル

使い方
1. index.html をダブルクリックして、Edge または Chrome で開きます。
2. 「動画を選ぶ」で端末内の動画ファイルを選択します。
3. 空白に隣接するピースをクリック・タップして、番号順に並べます。
   矢印キーでも操作できます（ピースが動く方向を指定）。

動画は自動ループ再生します。音声は「音声を再生」で有効にできます。
ウインドウのサイズに合わせて、動画の縦横比を保ちながら盤面を調整します。
完成すると右下の映像も表示されます。「シャッフル」で再挑戦できます。
「1手戻す」、番号・完成見本の表示切り替え、全画面にも対応しています。

インストール・インターネット接続・動画のアップロードは不要です。
動画の対応形式はブラウザによります。MP4（H.264）やWebMをお試しください。
動画を一時停止しても、ゲームの経過時間は進みます。
ファイルやプレイ状況は保存されないため、ページを閉じるとリセットされます。

検証：JavaScript構文、1,000回のシャッフルの可解性と移動処理を確認済み。
実際のブラウザ上での動画再生・表示の確認は未実施です。

「なめらかに移動」（初期状態：オン）で、ピースを約0.18秒かけてスライドさせます。
オフにすると瞬時に移動します。移動中も動画は再生されます。

「ギブアップ」で現在の配置から完成まで1手ずつ自動移動します。
自動移動中も動画は再生され、「なめらかに移動」の設定が反映されます。
「自動移動を停止」で途中停止し、手動で続けられます。
シャッフルと操作履歴から戻り道を求めるため、最短手順とは限りません。

ゲームモード
・15パズル：空白に隣接するピースを動かします。番号ガイドは切り替え可能です。
・入れ替えパズル：16枚すべてを使います。2枚を順番にクリックして入れ替えます。
  選択中は緑の枠で表示され、同じピースを再クリックすると選択解除します。
  数字ガイドは表示しません。
両モードで「なめらかに移動」「1手戻す」「ギブアップ」を利用できます。
モードを切り替えると、その動画のまま新しいゲームを開始します。

クリア演出
最後のピースの移動後、分割線が白く光って消え、CLEAR! とステップ数・時間を表示します。
クリックまたはキー入力で表示を閉じると、分割線のない動画を繰り返し再生します。
15パズル・入れ替えパズルの両方で、ギブアップによる完成時にも演出します。

マス数の変更
画面上部の「マス数」で3×3～16×16の14段階から選べます（初期値4×4）。
両モードに反映され、スライドモードは縦横のマス数の2乗から1枚少ないピース数になります。
マス数変更時は、同じ動画を使ってゲームを最初から開始します。
シャッフル、自動クリア、番号、クリア演出も選んだ分割数に対応します。

入れ替えモードでは、ピースが正しい位置に入ると、そのピースだけ約0.28秒白く光ります。
なめらか移動がオンの場合は到着後に光り、2枚とも正解した場合は両方が光ります。
最後のピースも光った後でクリア演出に移ります。最短探索機能は追加していません。

両モードとも、正しい位置にあるピースは白枠、正しくない位置のピースは黒枠で表示します。
移動中は黒枠になり、到着した位置に応じて枠色を更新します。空白マスは白枠になりません。
クリア演出後は従来どおり枠を消して動画全体を再生します。

正解マスの表示を更新：白枠を廃止し、正しい位置のピースは枠の分まで映像を広げてマス全体に表示します。
正解ピース同士は線なしでつながり、不正解の位置へ動かすと黒枠付き表示に戻ります。

「表示と操作」→「枠の色」で黒・白を切り替えられます（初期値：黒）。
両モードに即座に反映され、ゲームの進行はそのままです。正解マスは枠なしのままです。

枠色の設定はボタンになりました。「枠の色：黒／白」を押すたびに切り替わります。

ゲームページ内では48pxサイズの大きなマウスカーソルを使います。
通常は白、盤面や操作ボタンの上ではミント色で表示します。
ブラウザのタブ・アドレスバーや他のアプリのカーソル設定は変更しません。

カーソルの形を肉球付きの猫の手に変更しました。
サイズは48px、通常はクリーム色、操作できる場所ではミント色です。指先がクリック位置です。

入れ替えモードでは、カーソルを重ねたコマと選択中のコマが、拡大と影で少し浮き上がります。
選択中のコマは強めに浮き上がり、カーソルを外しても選択解除するまで維持されます。
交換中・自動クリア中・クリア後には浮き上がりを解除します。

スライドモードのドラッグ操作
空白マスを押したまま上下左右へドラッグすると、その方向の隣接コマと連続交換できます。
マウス・タッチ・ペンに対応し、速いドラッグで複数マスを通過しても順番に動きます。
指やボタンを離すと、そこまでドラッグした分の移動を完了します。
従来のクリック・矢印キー操作も利用できます。
